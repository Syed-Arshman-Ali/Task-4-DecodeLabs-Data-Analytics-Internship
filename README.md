# DecodeLabs Internship: Project 4 - Data Visualization

## 📌 Project Overview
This repository contains the final Optional Mastery Phase project for the DecodeLabs Data Analytics Internship. The primary objective of this task was to transition from exploratory data analysis to explanatory business storytelling by designing a boardroom-ready executive presentation slide.

## 🎯 Objective
To analyze an e-commerce sales dataset, identify the highest-performing product categories by total revenue, and present the findings using clean, distraction-free data visualization principles (maximizing the data-ink ratio).

## 🛠️ Tools Used
* **Microsoft Excel:** PivotTables, data aggregation, and 2D Clustered Bar chart creation.
* **Microsoft PowerPoint:** Presentation layout, typography, and applying the SCR (Situation, Complication, Resolution) narrative framework.

## 📊 Key Insights & Execution
* **Data Isolation:** Filtered the core dataset to compare `Product` against `Total Price`.
* **Visual Editing:** Eliminated "chartjunk" (gridlines, legends, 3D effects) and utilized direct data labeling to reduce cognitive friction.
* **The Spotlight Rule:** Applied a muted grey baseline with a bold accent color to highlight the top-performing category. 
* **Business Resolution:** Delivered an action-oriented conclusion, revealing that Chairs and Printers drove the highest total revenue, alongside a strategic recommendation to increase Q4 marketing allocation for those items.
